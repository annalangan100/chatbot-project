# Chatbot Project

A chatbot built in Python while learning software development, Git, GitHub, and chatbot architecture.

## Project Goals

This project is being developed incrementally to learn:

* Python programming
* Git and GitHub workflows
* JSON data handling
* Chatbot design
* Natural Language Processing (NLP)
* Machine Learning concepts

## Current Features

* Command-line chatbot
* Responses stored in JSON
* Modular project structure
* Git branch workflow
* GitHub version control

## Project Structure

```text
chatbot-project/
│
├── chatbot.py
├── responses.json
├── README.md
├── requirements.txt
└── .gitignore
```

## Installation

Clone the repository:

```bash
git clone https://github.com/annalangan100/chatbot-project.git
cd chatbot-project
```

## Run the Chatbot

```bash
python chatbot.py
```

## Example Conversation

```text
You: hello
Bot: Hello!

You: how are you
Bot: I'm doing well, thanks for asking!

You: bye
Bot: Goodbye!
```
