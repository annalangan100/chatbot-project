# Chatbot Project

A Python chatbot project built while learning chatbot development.

## Features

* Python-based chatbot
* Interactive command-line interface
* Version controlled with Git
* Will be expanded with AI capabilities

## Installation

```bash
git clone https://github.com/annalangan100/chatbot-project.git
cd chatbot-project
```

## Run

```bash
python chatbot.py
```
